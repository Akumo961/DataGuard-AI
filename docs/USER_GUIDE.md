# User Guide

1. Sign in through the organization's approved identity provider.
2. Select an authorized organization workspace.
3. Submit an approved document/text source.
4. Review detected PII categories and confidence.
5. Review the explainable risk score and contributing factors.
6. Validate findings and correct false positives according to analyst permissions.
7. Create or update a PIA when the project requires one.
8. Track remediation and review evidence.

Treat automated findings as decision support. Confirm consequential findings with an authorized privacy/security reviewer and do not upload real sensitive data unless the environment and purpose are approved.
