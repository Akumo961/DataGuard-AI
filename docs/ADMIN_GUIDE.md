# Administrator Guide

Configure identity integration, organizations/roles, database connectivity, Redis/job infrastructure, allowed origins/hosts, retention policy, logging and backup procedures through the deployment environment.

Administrators should use least privilege, rotate secrets through the approved secret manager, review security/audit events, verify backups, and approve framework/model changes through change control.

Never place real personal information in development/demo environments. Production administrators must follow the organization's privacy, security and records-retention policies.
