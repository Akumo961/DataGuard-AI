# Phase 7 — Compliance Framework

## Repository evidence

The repository contains a versioned machine-readable compliance framework under `compliance/frameworks/` for Québec privacy, Canadian privacy, GDPR and CCPA/CPRA-oriented controls.

Controls are represented as configurable assessment content and are not hardcoded legal conclusions.

## Limitation

Legal references and applicability require qualified review before use in a government deployment. The platform does not certify compliance automatically.
