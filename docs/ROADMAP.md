# Roadmap

## Completed foundation

Phases 1–14 established the audit baseline, architecture, security foundation, tenant-aware persistence, layered detection, risk engine, configurable compliance controls, PIA workflow, document processing, API, frontend, audit/evidence, testing and deployment baseline.

## Next hardening

- Phase 16: safe synthetic government demonstration environment.
- Phase 17: procurement/commercial package.
- Target-environment OIDC/JWKS integration and privileged access management.
- Durable append-only/WORM evidence storage.
- Malware scanning and isolated processing workers.
- Enterprise connectors and integration testing.
- Reproducible ML datasets/evaluation and model governance.
- Observability, SBOM, signed artifacts and deployment acceptance testing.

Roadmap status is implementation-specific; none of the remaining items should be represented as completed until verified in code and tests.
