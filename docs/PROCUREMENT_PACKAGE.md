# DataGuard Québec — Procurement Package

## Offering

DataGuard should be positioned as a platform plus implementation and lifecycle service, not as a claim of guaranteed legal compliance.

### Platform licensing

- Starter: small teams, core discovery, PII analysis and governance workflows; indicative commercial price to be negotiated.
- Enterprise: organization-wide deployment, integrations, advanced governance and support; pricing based on users, data volume, environments and integrations.
- Government: negotiated multi-year agreement covering sovereignty/residency requirements, enterprise support, security controls, integrations and governance needs.

No prices in this document represent an existing contract or market quotation.

## Professional services

- Discovery and architecture
- Integration/connectors
- Data migration and inventory onboarding
- Security hardening
- Private/cloud deployment
- Configuration/customization
- PIA and governance workflow configuration
- Training and change management
- Validation and acceptance support

## Lifecycle services

- Support and maintenance
- Security updates
- Compliance-control content updates
- Model evaluation/improvement
- Operational reviews

## Procurement evaluation criteria

Buyers should evaluate security architecture, tenant isolation, identity integration, data residency, evidence retention, model validation, connector coverage, accessibility, operational support, disaster recovery and implementation references.
